# Note on the Original Project Name

The solution, project, assembly, root namespace (`Al_Qaeda_Fying`) and window title of this program use a name chosen by the author when the project was created during their early university years.

In March 2025 the author replaced the repository README with a public apology for that choice. It acknowledges that the name is insensitive and inappropriate given its historical weight, and expresses regret to anyone it may have offended. The statement is preserved unchanged in [`original/original-readme.md`](original/original-readme.md).

## Why the name still appears in the repository

The goal of this reorganization is to **preserve the original implementation exactly as it was written**. The name appears in:

- file and folder names (`Al Qaeda Fying.sln`, `Al Qaeda Fying/`, `Al Qaeda Fying.csproj`, `Al Qaeda Fying_TemporaryKey.pfx`);
- the paths inside the solution file (`Al Qaeda Fying\Al Qaeda Fying.csproj`);
- the C# namespace in every source file;
- the compiled binaries, resources and embedded logo image.

Renaming any of these would mean editing source code, project configuration or binaries, which this reorganization deliberately avoids. The name is kept only as part of the historical record. The repository itself is presented as **Airline Route Optimization**.
